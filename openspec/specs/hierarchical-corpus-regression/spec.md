# hierarchical-corpus-regression Specification

## Purpose
定义「层次化路径在**既有语料**上有没有**回归栅栏**」这条**流程契约**：★ 既有语料里
**带子组件**的 DUT MUST 被层次化路径覆盖（或**显式豁免** + 原因）⇒ ★ 覆盖 MUST 有
**登记表** ⇒ ★ 登记表 MUST 与**实际用例**、与**语料本身**三方**双向核对** ⇒ ★ 覆盖 MUST
**登记其判别力上限**。

⚠️ **边界**：本 capability **不**管产物结构（★ 归 `rtl-hierarchical-output`）⇒ ★
**不**管等价性判据**本体**（★ 归 `rtl-hierarchical-output`）⇒ ★ **不**管「层次化路径的
公共 API」（★ 归 `hierarchical-equivalence-public-helper`）⇒ ★ **不**管「发射器/分析层
的行为正确性」（★ 那是本 capability 的**被测对象**，不是它的规范）。

## Requirements

### Requirement: 语料里的带子组件 DUT MUST 被层次化路径覆盖或显式豁免

层次化路径 MUST 在**既有语料**上有可机械核验的覆盖 ⇒ ★ **所有**在既有语料里**带子组件**
的 DUT MUST 出现在覆盖登记表里 ⇒ ★ **或**出现在**显式豁免**清单里并附**原因** ⇒ ⇒ ⇒
**既未覆盖也未豁免** MUST 被判为不合格。

⇒ ⇒ 该要求 MUST 由**机器**核验 ⇒ ⇒ ⇒ 「登记表」与「实际用例」与「语料本身」三者 MUST
**双向核对** ⇒ ⇒ ⇒ ⇒ 固定清单 MUST NOT 被当成栅栏（★ 清单是快照，不是围栏）。

#### Scenario: 新增语料时栅栏不会静默退化

- **WHEN** 既有语料里新增了一个**带子组件**的 DUT
- **THEN** 该 DUT MUST 出现在覆盖登记表里 ⇒ ⇒ **或** 出现在**显式豁免**清单里并附原因
      ⇒ ⇒ ⇒ 否则 MUST 被判为不合格 ⇒ ⇒ ⇒ ⇒ 覆盖 MUST 随语料增长而增长

#### Scenario: 豁免不是垃圾桶

- **WHEN** 豁免清单里列了一个 DUT
- **THEN** 该豁免 MUST 附**具体**原因 ⇒ ⇒ ⇒ 且该 DUT MUST **确实**存在于语料里
      ⇒ ⇒ ⇒ ⇒ 为一个早已不存在的 DUT 豁免 MUST 被判为不合格

### Requirement: 覆盖 MUST 登记其判别力上限

每条覆盖 MUST 登记其**判别力上限** ⇒ ★ 恒相关信号（两个被观测信号逐拍同值 ⇒ ⇒
「逐拍全等」**分不清**它们被交换）⇒ ★ 顶层只有**一个**可观测输出（⇒ ⇒ 「观测集合内部
互换」这一维**不存在**）⇒ ★ **纯组合** DUT（⇒ ⇒ 子组件的**时序缺陷**结构性测不出）
⇒ ★ 已知的**观测值偏差**（⇒ ⇒ 比对时 MUST NOT 把它当缺陷）⇒ ★ **不可**层次化的 DUT
（⇒ ⇒ MUST 登记其**拒绝原因**）。

⇒ ⇒ 登记 MUST 覆盖「顶层可见」的 DUT ⇒ ★ 顶层不可见的 `ch_out` MUST NOT 被登记为
「已覆盖」（★ 那会**虚报**覆盖面）。

#### Scenario: 恒相关信号被登记而非静默通过

- **WHEN** 一个被观测信号是其它被观测信号的**确定函数**
- **THEN** 覆盖登记表 MUST 记录该**上限** ⇒ ⇒ ⇒ 且 MUST NOT 声称「逐拍全等 ⇒ 无缺陷」

#### Scenario: 不可层次化的 DUT 登记其拒绝原因

- **WHEN** 某个 DUT **不可**层次化（★ 例如它的输出依赖子组件的**非端口**内部线网 ⇒ ⇒
      需要隐式端口合成）
- **THEN** 该 DUT MUST 出现在登记表里并记录**拒绝原因** ⇒ ⇒ ⇒ 拒绝原因 MUST **点名**
      ⇒ ⇒ ⇒ 用户 MUST 知道该改哪

### Requirement: 覆盖 MUST 由机器核验且 MUST 自证有判别力

覆盖判据 MUST 可**独立运行**（★ 不依赖人工触发）⇒ ★ MUST 对「登记表」「实际用例」
「语料本身」做**三向双向核对**⇒ ★ 且该核对 MUST 有**自证**：每条判据 MUST 有**投毒**
对照 ⇒ ⇒ ⇒ **无投毒**的核对 MUST 被视为**无判别力**。

#### Scenario: 核对本身有判别力

- **WHEN** 登记表被**改动**（★ 删掉一行 / 加一个不存在的条目）
- **THEN** 核对 MUST **转红** ⇒ ⇒ ⇒ 且还原后 MUST 复绿

#### Scenario: 覆盖判据进 CI

- **WHEN** 覆盖护栏存在
- **THEN** 它 MUST 出现在**持续集成**的执行清单里 ⇒ ⇒ ⇒ ⇒ 否则「回归栅栏」只是一次性
      本地证据
