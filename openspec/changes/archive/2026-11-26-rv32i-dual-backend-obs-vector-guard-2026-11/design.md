## 1. 判据设计（4 条 · 全部可机械判定）

记：
- `P` = 核顶层 `ch_out` 端口名集合（今日 **39**）
- `V` = 跨后端比对向量（`kObsNames[]`）（今日 **28**）
- `R` = 缺口登记表里的端口名集合（今日 **11**）

| # | 判据 | 形式化 | 今日 | 失败文案 |
|---|---|---|---|---|
| **C1** | 守恒 | `\|V\| + \|R\| == \|P\|` | 28 + 11 = 39 ✅ | `❌ C1 守恒失败：向量 27 ≠ 39 − 11` |
| **C2** | 登记有效（防编造） | `R ⊆ P` | ✅ | `❌ C2 登记无效：'axil_xxx' 不存在于核顶层 ch_out（禁止编造豁免）` |
| **C3** | 登记不 stale（防过期） | `R ∩ V == ∅` | ✅ | `❌ C3 登记 stale：'axil_awaddr' 已在向量里（补齐后 MUST 清账）` |
| **C4** | 归属（防新增端口失同步） | `V ∪ R == P` | ✅ | `❌ C4 端口失同步：'axil_new_port' 既不在向量、也不在登记表` |

> **C1 与 C4 不重复**：C1 只判**条数**（`|V|+|R| == |P|`）⇒ 条数对但**内容错**时 C1 恒绿
> （例：向量里换掉一个名字、登记里换掉另一个）⇒ ⇒ C4 判**集合相等**才堵住这一格。
> ⇒ ⇒ **两条都要**（与 `DUAL_BACKEND_PARITY_TOTAL` / `PAIRS` 的「广度 + 深度」同型：单条都有盲区）。

## 2. 数据来源与解析规则（**钉死格式 ⇒ 不靠约定**）

| 数据 | 来源 | 解析规则 |
|---|---|---|
| `P` | `examples/riscv-mini/src/rv32i_core_top.h` | 行匹配 `ch_out<...>\s+([A-Za-z_]\w*)\s*\{`（`__io` 块内的具名构造）· 剥注释（`//` / `/* */`）后再匹配 |
| `V` | `examples/riscv-mini/tests/test_rv32i_soc_dual_parity.cpp` | 取 `kObsNames[] = { ... };` 的初始化列表内的**全部字符串字面量** |
| `R` | `.rddf/checks/rv32i-obs-vector-registry.md` | 表格数据行第 1 列的**反引号内标识符**（`| `axil_awaddr` | ... |`） |

**为什么这三处形态稳定**：
- `P` 的具名构造（`ch_out<T> name{"name"}`）是 `PORT-NAMING-GUIDE` 的推荐形态，且 `verify_port_naming.sh` 守着 ⇒ 不会退回匿名形态；
- `V` 是 `constexpr` 数组字面量（C++ 无其它写法能达到「编译期下标查找」）；
- `R` 用 markdown 表（与 `.rddf/checks/input-port-required-registry.md` 同范式）。

**fail-closed**：三处任一**解析为空** ⇒ `exit 2`（不是 PASS）—— 否则「正则失效」会伪装成「零违规」。

## 3. 缺口登记表格式（`<name>` 级双向可判）

```markdown
| 端口 | 方向/宽度 | 为什么**未纳入**跨后端向量 | 归位条件 |
|---|---|---|---|
| `axil_awaddr` | out / 32 | S4a 加通道时**未同步**向量（change `rv32i-soc-mmio-channel-2026-11`）⇒ ⇒ 该通道 19 端口整体在证据之外 | 步 2：`rv32i-obs-vector-axil-2026-11` 把 11 根输出加进 `kObsNames[]` + 驱动 8 根输入 + 固件加 MMIO 事务 ⇒ 本行 MUST 删除 |
| … | | | |
```

- **为什么未纳入** 列 MUST 非空（禁「TBD」）⇒ 空 ⇒ 判据红（登记不得是无理由的豁免）；
- **归位条件** 列 MUST 指向一个具体的后续 change 名或判据 ⇒ 空 ⇒ 红。

## 4. 自检（5 类投毒 · 逐条必红 · 还原复绿）

| # | 投毒 | 期望命中 |
|---|---|---|
| **P1** | 从 `kObsNames[]` 删一项 | C1（条数）/ C4（归属） |
| **P2** | 登记表加一行**不存在的**端口名 | C2 |
| **P3** | 登记表删一行（缺口变少） | C1 / C4 |
| **P4** | 核顶层加一个 `ch_out` 端口（既不进向量也不进登记） | C1 / C4 |
| **P5** | 把一条登记里的端口**也加进向量**（补齐后忘清账） | C3 |

自检**不依赖真实仓**：fixture 在三份临时文件上做（`tempfile.mkdtemp`）⇒ 不改真实文件、不依赖 git 历史 / 网络 / verilator（可达性纪律 1/2）。
