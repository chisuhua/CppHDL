# **删除留痕**（audit trail）—— 不参与任何「豁免」判定。
#
# ⚠️ 为什么与 `examples/disabled_examples.txt` 分开（2026-10-23，对抗审稿 B3）：
#    `disabled_examples.txt` 的语义是「**存活但未跑** ⇒ 豁免」，判定方式是**按名字**。
#    把「删除留痕」也塞进那个文件，会让它变成**按名字的永久自动豁免** ——
#    实测：新建一个与已删项**同名**的测试（且不注册进 CTest），
#    `scripts/verify_example_test_wiring.sh` 与 `run_all_ported_tests.sh` **双绿**。
#    ⇒ 删除留痕 MUST 与豁免分开，且**不得**被当成「该名字已豁免」。
#
# 格式：<target 名>	<删除理由>	<归位条件>
#
# 本文件的唯一用途：**人可读的审计记录**（为什么删、什么条件下重建）。
# ⚠️ 它**不参与任何自动化判定** —— 护栏只读 `disabled_examples.txt`。
#    （「旧构建目录残留孤儿二进制」这一情况已由 `run_all_ported_tests.sh` 的
#      `is_declared_target()` 判为 STALE-ARTIFACT，无需本文件参与。）
#
# 与 C2 锚点（root `AGENTS.md` 的 `EXAMPLES_TEST_SOURCES`）的关系：
#   本文件里的每一条都对应一次**已发生**的源文件减少 ⇒ 当初必然同步改小了
#   那个锚点。锚点是「防静默缩面」的机制，本文件是「那次缩面的理由」。
