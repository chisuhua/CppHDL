# examples/disabled_examples.txt
#
# 登记**未被运行护栏跟踪**的 example 程序 / 测试二进制。
#
# 格式：<名字> <TAB> <为什么不被跟踪> <TAB> <归位条件：什么时候回来>
#
# 为什么需要它：护栏 `run_all_ported_tests.sh` 的跟踪集合只有**一处**
# （`examples/CMakeLists.txt` 的 `CH_TRACKED_EXAMPLE_TARGETS`）⇒ 任何
# 「不在集合里」的 program 就会**静默地**从运行覆盖中消失 ⇒ 「新增即漏」
# （与 `samples-regression-guard-2026-10` 的 C1 同型 —— samples 侧的对应物是
# `samples/disabled_samples.txt`）。
#
# ⚠️ 本清单只做**登记**，不负责修复（修复是独立工作，见归位条件列）。
# ⚠️ 归位条件一旦达成，MUST 从本清单移除该行**并**补进
#    `CH_TRACKED_EXAMPLE_TARGETS`。
#
# 判定基准（2026-10-23 实测）：
#   被跟踪 28 / main() 程序 32（其中 4 个未被跟踪）/ 本清单 5
#   （5 = 4 个未跟踪的 main() 程序 + 1 个「已构建但不进 CTest」的 target）
#   ⚠️ 已删除 target 的**删除留痕不在本清单**，在 `examples/removed_examples.txt`。
#   ⚠️ 2026-10-23 起，`examples/riscv-mini/` 的 14 个 Catch2 target **已进
#   CTest**（`add_test`）⇒ 它们不再登记在本清单（归位条件已达成 ⇒ MUST 移除）。
#   ⚠️ **已删除 target 的删除留痕不在本清单**，在 `examples/removed_examples.txt`
#      （8 条：6 个曾声明过的 CMake target + 2 个从未进 CMakeLists 的孤儿源文件）。
#      两个文件 MUST 分开：本清单是「**存活但未跑**」的豁免（按名字判定），
#      那一份是纯审计记录（**不参与任何自动化判定**）—— 混在一起会让删除留痕
#      退化成「按名字的永久自动豁免」（新建同名测试会静默通过）。
